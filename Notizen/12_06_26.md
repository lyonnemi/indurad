#### logger configurations [technical]
- by declaring a logger with a name and configuring it in a file, any other declaration will have the same configuration
```python
import logging
 #file1
logging.basicConfig(
	level=logging.DEBUG
)

logger = logging.getLogger("name")
logger.setLevel(logging.DEBUG)

#file2
logger = logging.getLogger("name") #already has the same configuration
```
